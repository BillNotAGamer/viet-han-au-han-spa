Phase 11 booking rate-limit review

Limiter:
- Name: booking-submissions
- Implementation: App\Providers\AppServiceProvider
- Threshold: 5 submissions per minute
- Key: client IP address, falling back to public-booking if no IP is available

Route application:
- POST /dat-lich uses throttle:booking-submissions
- POST /en/booking uses throttle:booking-submissions
- GET booking routes are not throttled by the named limiter

Test evidence:
- PublicBookingTest::test_booking_post_is_rate_limited proves the sixth POST from an isolated IP receives HTTP 429.
