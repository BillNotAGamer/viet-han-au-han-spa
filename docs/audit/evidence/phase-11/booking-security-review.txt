Phase 11 booking security review

CSRF:
- Public form includes @csrf.
- Routes use Laravel web middleware.

Protected public fields:
- Public request cannot set status.
- Public request cannot set admin_note.
- Public request cannot set locale.
- Public request cannot set lifecycle timestamps.
- Public request cannot set reference.
- Public request cannot set attribution/system fields.

Persistence:
- BookingRequestCreator force-sets status NEW.
- Locale is derived from canonical route middleware/app locale.
- Service selection is revalidated against PUBLISHED + exact requested-locale Service translation.

Public privacy:
- No public route lists or shows booking requests.
- Successful POST redirects without exposing a booking ID.

Admin:
- Filament access remains behind existing users.is_admin panel rule.
- BookingPolicy permits admin view/update/restore and prohibits public/admin create, delete, and force-delete.
