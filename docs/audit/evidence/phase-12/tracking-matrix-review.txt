2. IDENTIFIER REGEX VALIDATION RULES
--------------------------------------------------------------------------------
- GTM Container ID: /^GTM-[A-Z0-9]+$/i
  * Matches: GTM-XXXXXXX, GTM-123456
  * Rejects: Invalid formats, XSS payloads (e.g., "GTM-123<script>alert(1)</script>")
  * Result: Discarded if non-matching; null returned.

- GA4 Measurement ID: /^G-[A-Z0-9]+$/i
  * Matches: G-XXXXXXXXXX, G-ABCDEF12
  * Rejects: Malformed characters, quotes, scripts
  * Result: Discarded if non-matching; null returned.

- Meta Pixel ID: /^[0-9]{5,25}$/
  * Matches: Digits only between 5 and 25 characters
  * Rejects: Non-numeric strings, SQL injection, script tags
  * Result: Discarded if non-matching; null returned.

3. DELIVERY MODE PRECEDENCE RESOLUTION
--------------------------------------------------------------------------------
Mode A: 'none' (Disabled)
  - Condition: tracking.enabled is false OR no valid IDs configured
  - Tags rendered: NONE
  - GTM / GA4 / Meta Pixel scripts: SUPPRESSED
  - GTM noscript iframe: SUPPRESSED
  - Conversion events: SUPPRESSED

Mode B: 'gtm' (GTM Priority Mode)
  - Condition: tracking.enabled is true AND tracking.gtm_container_id is valid
  - GTM Script (<head>): INJECTED
  - GTM Noscript (<body>): INJECTED
  - Direct GA4 tag: STRICTLY SUPPRESSED (even if tracking.ga4_measurement_id is configured)
  - Direct Meta Pixel tag: STRICTLY SUPPRESSED (even if tracking.meta_pixel_id is configured)
  - Rationale: Prevents double-counting of PageView and Lead conversions when GTM tags GA4/Meta internally.

Mode C: 'direct' (Direct Delivery Mode)
  - Condition: tracking.enabled is true AND tracking.gtm_container_id is absent/invalid AND (GA4 or Meta Pixel ID is valid)
  - GA4 Script: INJECTED if tracking.ga4_measurement_id is valid
  - Meta Pixel Script: INJECTED if tracking.meta_pixel_id is valid
  - GTM Script & Noscript: SUPPRESSED
