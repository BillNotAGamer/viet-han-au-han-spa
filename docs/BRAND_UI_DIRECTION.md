# BRAND & UI DESIGN DIRECTION

**Brand Name:** Việt Hàn Âu Hàn Spa  
**Design Reference:** `https://zenmassagespa.vn/` *(Reference for UX layout, spacing, and wellness flow only — no direct copying of assets or text)*  

---

## 1. Brand Essence & Mood

* **Tone & Persona:** Luxury Asian Wellness, Warm, Serene, Highly Refined, Trustworthy, Meditative.
* **Atmosphere:** Natural aromatherapy ambiance, gentle lighting, authentic Korean/Vietnamese therapeutic spa traditions blended with modern aesthetics.

---

## 2. Color Palette & Tokens

The color palette is derived from the official Việt Hàn brand heritage:

| Color Role | Color Name | Hex Code / Tailwind Token | Usage Guidance |
| :--- | :--- | :--- | :--- |
| **Primary Base** | Deep Burgundy / Royal Red | `#6A141A` / `burgundy-900` | Primary brand touchpoints, badges, hero accents, footer base. |
| **Secondary Accent** | Warm Gold | `#D4AF37` / `gold-500` | CTA buttons, borders, subtle divider lines, star ratings, premium highlights. |
| **Tertiary Accent** | Champagne Gold | `#E8D8A6` / `gold-200` | Soft hover states, subtle badge backgrounds. |
| **Background (Light)** | Warm Cream / Ivory | `#FBF9F4` / `cream-50` | Main website background for a gentle, warm eye feel (avoids harsh pure `#FFFFFF`). |
| **Surface Card** | Soft Linen / Off-White | `#F5F0E8` / `cream-100` | Service cards, testimonial containers, pricing boxes. |
| **Text Primary** | Deep Charcoal / Dark Espresso | `#231F20` / `charcoal-900` | Headings, body copy, icons (avoids harsh pure `#000000`). |
| **Text Muted** | Warm Slate / Muted Earth | `#6E675F` / `charcoal-500` | Subtitles, duration badges, author metadata, footers. |

> [!IMPORTANT]
> **Gold Balance Rule:** Gold should be used purposefully as an accent for highlights, buttons, and badges. Avoid excessive gold gradients or garish royal styling to maintain a modern, tranquil aesthetic.

---

## 3. Typography Hierarchy

* **Display & Heading Font:** Google Font `Cinzel` or `Playfair Display` (Serif, elegant, luxurious, high-fashion).
* **Body & UI Font:** Google Font `Plus Jakarta Sans` or `Inter` (Clean, highly legible on mobile screens, supporting full Vietnamese diacritics).

---

## 4. UI/UX Principles

1. **Generous Whitespace:** Allow high breathing room between sections (py-16 to py-24 on desktop) to evoke calm and luxury.
2. **Photography-First:** Use large, curated spa imagery (warm candlelight, herbal oils, wooden bowls, clean towels, serene treatments).
3. **Subtle Micro-Interactions:** Gentle fade-ins, smooth card hover elevations, and warm button transitions.
4. **Mobile-First Accessibility:** Bottom-docked "Book Now" CTA on mobile viewport for high booking conversion rate.
5. **Asset Note:** Real brand logo files will be provided by the client prior to Phase 8 (Design System).
